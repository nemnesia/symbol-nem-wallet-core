# Review Gates

1. 正確性: package名、install、import、API、引数、戻り値、対応環境、機能説明が実装・manifestと一致する。
2. 利用可能性: 利用者が必要な前提を満たして最初の利用まで進める。
3. 制約の正確性: 未実装、将来、chain / network、security、capability、保証範囲を誤解なく区別できる。
4. 整合性: README、公開API、仕様、設定、テスト、licenseに利用を妨げる矛盾がない。
5. 構成: 最初の利用に必要な情報が詳細・内部仕様に埋もれていない。

ERROR / WARNがなければ品質ゲート合格。NITだけでは不合格にしない。
