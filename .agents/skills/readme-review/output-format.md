# Output Format

この Skill のレビュー成果物は、`../review-common/output-format.md` の共通構成・章名・順序・指摘必須項目を使用する。共通構成を省略、追加、並べ替えない。

## Skill-specific values

- Formal finding prefix: `RM`
- Severity: `ERROR` / `WARN` / `NIT`
- Review Result: `READY` / `READY WITH MINOR FIXES` / `REVISE README`
- Required Changes: `ERROR` / `WARN` の New / Open / Reopened
- Optional Improvements: `NIT` の New / Open / Reopened
- Deferred Findings: README の責務を越え、製品・仕様・実装側で決める事項
- Domain Checks: Documentation Checks（install、API、環境、制約、license、links、examples）
- Scope and Traceability: README と manifest、公開 API、実装、仕様、テスト、設定の対応
